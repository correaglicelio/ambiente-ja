# Ambiente Já

Focos de calor do seu município, comparados com o mesmo período do ano passado. Dados abertos do INPE (Programa Queimadas).
Faz parte do **Hub Já**: https://hubja.com.br/ambiente-ja/

Foco de calor **não** é o mesmo que incêndio: é um ponto que o satélite viu quente. Pode ser queimada controlada, incêndio ou outra fonte de calor.
